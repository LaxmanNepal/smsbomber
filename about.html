SMS Bomber NP

About the Educational Lab

This project is a browser-only security demonstration for learning about input validation, rate limiting, monitoring and privacy.

What it does

  • Validates fictional Nepal mobile-number formats.
  • Simulates allowed and blocked events.
  • Displays defensive security metrics.
  • Keeps processing inside the browser.

What it does not do

It does not send SMS messages, contact SMS providers, trigger OTPs, use Firebase workers, or make external delivery requests.
