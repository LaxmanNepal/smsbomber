SMS Security Lab

A safe recreation of an SMS-bomber-style interface for learning about validation, rate limiting, OTP abuse, logging, and defensive controls. It never contacts an SMS provider and never sends a real message.

⚠️ Simulation only. Network sending is intentionally disabled. Use this lab to study how abuse can be detected and prevented.
