# SMS Security Lab — Nepal

A safe, browser-only educational simulator inspired by SMS-bomber-style interfaces.

## Purpose

This project demonstrates defensive concepts around OTP abuse:

- Nepal mobile-number validation
- Request/event simulation
- Local rate limiting
- Block-rate metrics
- Security event logging
- Responsive web UI

## Safety

The simulator **does not send SMS**, call OTP providers, or make external network requests. The original real-provider request functions are intentionally not included.

Use the project for security education, UI experimentation, and defensive testing in controlled environments.

## Run

Open `index.html` in a browser. No build system or external dependency is required.
